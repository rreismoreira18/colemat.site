# Site Grupo Colemat

Página estática (HTML, CSS e JavaScript). Não precisa de instalação nem de build.

- `index.html`: a página inteira (estilos e scripts incluídos)
- `img/`: logo, mascotes e fotos

Para ver no computador, abra `index.html` no navegador.
Para publicar na Vercel: importe este repositório, escolha o preset **Other** e deixe build e output em branco.
